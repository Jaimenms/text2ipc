# CLAUDE.md

Study repository for **text-to-IPC**: given free text (typically a patent abstract, in
Portuguese or English), return a ranked list of International Patent Classification
symbols at a chosen hierarchy level. Packaged as `text2ipc`, intended for PyPI.

## What this repo optimizes for

1. **A tiny public interface.** `classify(text, version, level)` and the `t2ipc` CLI.
   Everything else is implementation detail that may change.
2. **Embeddings plus hierarchy, no training.** Each IPC entry is embedded once from its
   full ancestor path; queries are embedded by paragraph (mean of the pieces) and scored
   by cosine, with path support, subtree support and beam descent available as
   parameters; an optional cross-encoder reranks the candidates
   (`docs/methodology.md`). No fine-tuned classifier, no LLM in the loop.
3. **Versions are first class.** WIPO publishes a scheme per year; indexes are built per
   version and reuse vectors from the previous version when the entry text is unchanged.
4. **Language is a dimension, not an afterthought.** The scheme language (EN/FR from
   WIPO, others by title overlay) and the query language (handled by a multilingual
   embedder) are independent. Portuguese queries are the first target.
5. **Evals from real office decisions.** INPI's weekly *Revista da Propriedade
   Industrial* supplies Portuguese titles/abstracts with the IPC symbols actually assigned.

## Layout

| Path | Purpose |
|---|---|
| `src/text2ipc/scheme/` | Download and parse the WIPO scheme XML; Portuguese titles from INPI's IPCPUB |
| `src/text2ipc/embeddings/` | Embedder protocol; sentence-transformers, Ollama and hash backends |
| `src/text2ipc/index/` | Parquet scheme/index tables, incremental build, discovery, publishing, CSV migration |
| `src/text2ipc/search/` | Hierarchical scoring heuristics |
| `src/text2ipc/chunking.py` | Paragraph and sentence chunks for texts over the embedder's limit |
| `src/text2ipc/rerank/` | Second stage: cross-encoder judges the candidates; `hash:` backend for tests |
| `src/text2ipc/eval/` | RPI parser, eval cases, hit-rate harness |
| `src/text2ipc/hf/` | Inference Endpoints handler and repository export |
| `src/text2ipc/web/` | Static Hugging Face Space export; `static/scorer.js` is a port of `search/scorer.py` |
| `src/text2ipc/classifier.py` | The public facade |
| `evals/` | JSONL eval cases (committed; derived from public RPI issues) |
| `notebooks/` | Study material, generated by `scripts/make_notebooks.py` and executed in place |
| `docs/adr/` | One file per decision that is expensive to reverse |
| `docs/usage.md` | End-user guide: endpoint, local install with prebuilt index, building, publishing |
| `scripts/` | Thin wrappers over the CLI |

Layout of the home: `wipo/` raw WIPO XML, `inpi/` raw INPI JSON, `rpi/` raw RPI
issues, `scheme/` derived scheme tables (parquet), `index/` vectors.
Downloads and built indexes go to `data/` inside this repo (gitignored; picked up
automatically when `data/` exists), or `$TEXT2IPC_HOME`, or `~/.cache/text2ipc` for
installed users. Prebuilt indexes are published to the Hugging Face Hub with
`scripts/publish_hf.sh` and fetched with `t2ipc download` (ADR 0005).

## Conventions

- Python ≥3.11, managed with `uv`. Never call `pip`; use `uv sync` / `uv run`.
- Code, identifiers, docstrings and docs are **English**. Eval texts are whatever
  language the source office publishes in.
- Tests never download anything and never load a real model: use the `hash:` embedder
  and the fixtures in `tests/fixtures/`.
- Notebooks are generated from `scripts/make_notebooks.py` (edit the script, not the
  `.ipynb`), stay thin (logic lives in the package) and must execute top-to-bottom
  with the PT and EN indexes built.
- The Parquet layout is a public contract (ADR 0006): scheme table
  `symbol, level, depth, parent, title, heading, path` and index table
  `symbol, path, text_hash, e000..eNNN` with metadata under the `text2ipc` key.
  Changing it needs an ADR and a migration command.
- An entry's vector is the embedding of the full top-down path text (section to the
  entry), rendered from the scheme table. Never embed a title alone.
- Any new heuristic needs: a doc section, a parameter with a default, a test on the
  mini scheme, and an eval run before and after on both `evals/rpi_*.jsonl` files,
  with the numbers appended to `docs/evals.md`.
- The browser demo scores with `src/text2ipc/web/static/scorer.js`, a port of
  `search/scorer.py` (ADR 0007). A change to the scorer is finished only when the port
  matches and `tests/test_web.py` (Node parity on the mini scheme) still passes.

## Commands

```bash
uv sync --all-extras
uv run t2ipc versions                                  # published IPC versions
uv run t2ipc build --version 20260101                  # embed the scheme, write CSV
uv run t2ipc build --version 20270101                  # reuses 20260101 vectors
uv run t2ipc build --version 20260101 --lang PT        # Portuguese titles from INPI
uv run t2ipc scheme --version 20260101 --lang FR       # scheme table only, no embedding
uv run t2ipc hf-export hf/text2ipc-pt --lang PT        # Hugging Face Inference Endpoints repo
scripts/publish_hf.sh --lang PT                        # export + upload to the Hub
uv run t2ipc web-export space/text2ipc --lang PT --lang EN   # static Space (browser demo)
scripts/publish_space.sh                               # export + upload the Space
uv run t2ipc download                                  # what an end user runs (from the Hub)
uv run t2ipc classify "texto do resumo" --level group
uv run t2ipc classify "texto do resumo" --lang PT --rerank   # + cross-encoder (2.2 GB model)
uv run t2ipc rpi 2100 --require-abstract               # eval cases (abstracts) from RPI 2100
uv run t2ipc eval evals/rpi_2100.jsonl --level subgroup
uv run t2ipc eval evals/rpi_2905.jsonl --lang PT --rerank      # second stage measured
uv run python scripts/make_notebooks.py && uv run jupyter nbconvert --to notebook --execute --inplace notebooks/01_text2ipc.ipynb
uv run pytest
uv run ruff check . && uv run ruff format .
```
